# Docudis MVP 上线清单

Docudis 的产品策略是所有功能免费开放；测试重点是隐私、稳定性和匿名化质量。

## 上线阻塞项

| 项目 | 验收标准 |
| --- | --- |
| 隐私政策 | 已托管，商店链接可公开访问，内容与当前 SDK 一致 |
| 真机回归 | Android 与 iOS 上覆盖粘贴、文件、相机、相册、分享和还原 |
| 模型交付 | Android App Bundle 的 asset pack 与 iOS Bundle NER model 均包含正确版本 |
| 数据安全 | 文档只在本机处理；商店申报 ML Kit 的诊断和安装标识信息 |
| 商店材料 | 四张截图、置顶大图、图标和三种商店语言已同步 |
| 自动检查 | `flutter analyze` 与 `flutter test` 通过 |

## 真机回归

1. 粘贴英文、法文、西班牙文和中文文本，检查识别、占位符和还原。
2. 上传文字型 PDF、扫描 PDF、DOCX 和图片，确认页面顺序与黑条位置。
3. 分享保留版面的打码 PDF、Word 和图片，并直接发送到已安装的 AI 应用。
4. 验证“总是遮住”“从不遮住”和“只遮住这个列表”。
5. 验证历史记录、重命名、单条删除和清除本机数据。
6. Android 验证 PROCESS_TEXT 与快捷设置入口；iOS 验证 Share Extension。
7. 开启飞行模式，确认已安装的本地模型仍可工作。

## 上线后关注

- 崩溃和无法处理的文件类型
- 漏检与误检样本，尤其是 OCR 表格和多栏页面
- 模型下载失败率与首次使用体验
- App Bundle / IPA 体积和冷启动时间
